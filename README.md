# Music Streaming Analysis Using Spark Structured APIs

## Overview

This project analyzes music streaming behavior using Apache Spark Structured APIs (PySpark).
It processes listening logs and song metadata to uncover user preferences, listening patterns,
and genre loyalty scores. The analysis is performed on a generated dataset simulating
real-world music streaming activity.

Remember to complete the README

## Dataset Description

The project uses two CSV datasets generated by `datagen.py`:

1. **listening_logs.csv** — Contains 1000 records of user listening activity:
   - `user_id` — Unique user identifier (user_1 to user_100)
   - `song_id` — Unique song identifier (song_1 to song_50)
   - `timestamp` — Date and time of the listening event
   - `duration_sec` — Duration of listening in seconds (30 to 300)

2. **songs_metadata.csv** — Contains metadata for 50 songs:
   - `song_id` — Unique song identifier
   - `title` — Song title
   - `artist` — Artist name (Artist_1 to Artist_20)
   - `genre` — Music genre (Pop, Rock, Jazz, Classical, Hip-Hop)
   - `mood` — Song mood (Happy, Sad, Energetic, Chill)

## Tasks and Outputs

### Task 1: User Favorite Genres

Identifies the most listened genre for each user by joining listening logs
with song metadata, grouping by user and genre, and ranking genres per user.  
**Output:** `outputs/favorite_genres.csv` — Contains user_id, genre, and listen_count for each user's top genre.


### Task 2: Average Listen Time

Calculates the average listening duration in seconds for each user across
all their listening sessions.  
**Output:** `outputs/avg_listen_time.csv` — Contains user_id and avg_duration_sec.

### Task 3: Genre Loyalty Scores - Top 10

Creates a custom Genre Loyalty Score for each user, defined as the percentage
of their total listens that belong to their top genre. Users are ranked by
this score and the top 10 are listed.  
**Output:** `outputs/genre_loyalty_scores.csv` — Contains user_id, genre, listen_count, total_listens, and loyalty_score for the top 10 users.


### Task 4: Night Owl Users (12 AM - 5 AM)

Identifies users who listen to music between 12 AM and 5 AM by extracting
the hour from the timestamp and filtering accordingly.  
**Output:** `outputs/night_owl_users.csv` — Contains user_id of all users who have at least one listening session between 12AM and 5AM.


## Execution Instructions

## *Prerequisites*

Before starting the assignment, ensure you have the following software installed and properly configured on your machine:

1. *Python 3.x*:
   - [Download and Install Python](https://www.python.org/downloads/)
   - Verify installation:
     ```bash
     python3 --version
     ```

2. *PySpark*:
   - Install using pip:
     ```bash
     pip install pyspark
     ```

3. *Apache Spark*:
   - Ensure Spark is installed. You can download it from the [Apache Spark Downloads](https://spark.apache.org/downloads.html) page.
   - Verify installation by running:
     ```bash
     spark-submit --version
     ```

### *2. Running the Analysis Tasks*

####  *Running Locally*

1. *Generate the Input*:
  ```bash
   python3 input_generator.py
   ```

2. **Execute Each Task Using spark-submit**:
   ```bash
     spark-submit main.py
   ```

3. *Verify the Outputs*:
   Check the outputs/ directory for the resulting files:
   ```bash
   ls outputs/
   ```

## Errors and Resolutions
| Error | Resolution |
|-------|------------|
| `JAVA_HOME not set` | Install Java 17 and set `$env:JAVA_HOME = "C:\Program Files\Java\jdk-17.0.19"` |
| `HADOOP_HOME unset` | Download winutils.exe and set `$env:HADOOP_HOME = "C:\hadoop"` |
| `Path does not exist: listening_logs.csv` | Move CSV files from root folder into the `input/` directory |
| `Permission denied on outputs/` | Run `icacls outputs /grant Everyone:F` |
| `No module named pandas` | Run `py -m pip install pandas` |
